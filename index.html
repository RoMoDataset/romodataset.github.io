Why RoMo exists

Motion generation deserves the data that moved language, image, and video

Generative models in other fields scaled because the community shared large, well-curated data and agreed on how to measure progress. 3D human motion has lagged behind.

The data gap

Small and clean, or large and noisy

Researchers choose between high-fidelity motion capture that is too small for modern generative models and in-the-wild collections dominated by static or low-quality sequences. Hands are often missing entirely, or treated as rigid end-effectors.

The comparison gap

Every paper, its own pipeline

Formats, representations, and evaluators are re-implemented from project to project. Aggregate scores hide category-specific failures, and results across papers are hard to compare or reproduce.

Our goal

Enable open motion generation research by giving the community large-scale, carefully curated data and shared tools to build on, compare against, and extend.

01 · Open data

Scale with quality gates

In-the-wild motion distilled through aggressive filtering, then released on Hugging Face for research use.

02 · Shared organization

One taxonomy, rich language

A three-level semantic taxonomy and detailed captions make it possible to evaluate per category, not just on average.

03 · Shared tools

Comparable by default

The Motion Toolbox standardizes metrics, format conversion, and visualization so results line up across papers.

Each dataset has its own project page, paper, and Hugging Face release. Both share RoMo's collection stack and taxonomy.

Code

Motion Toolbox

One open-source library to measure, convert, and view motion across the ecosystem, so a result on RoMo means the same thing in every paper.

  • Standard metrics FID, R-Precision, diversity, multimodality, and per-category scores computed the same way everywhere.
  • Format conversion SMPL, HumanML3D 263-D, 272-D, and MHR body formats with consistent root-motion handling.
  • Visualization Interactive browser viewers and GLB export, the same pipeline behind the RoMo motion gallery.

How it fits together

One collection stack, many kinds of motion

Every RoMo dataset starts from the same curated web video, temporal segmentation, and semantic taxonomy. New motion types branch from that shared foundation, and the Motion Toolbox ties them back together.

Build with RoMo

Use it, compare on it, extend it

The ecosystem gets more useful as more people train on it, report against it, and contribute back.

Train

Start from scale

Download a dataset from Hugging Face in the representation your model expects: SMPL, HumanML3D 263-D, 272-D, or the 393-D hand representation.

Compare

Report on shared ground

Evaluate with the Motion Toolbox and report per-category results, so improvements are visible where they actually happen.

Contribute

Grow the toolbox

Add converters, metrics, and viewers on GitHub so the next dataset and the next paper start further ahead.
